# C# OOP Quiz

A college-style **30-question / 30-mark C# OOP MCQ quiz** built with HTML, CSS and JavaScript.

## Sections
- C# Basics — Q1–Q6
- Constructor & OOP — Q7–Q12
- Abstract, Sealed & Static — Q13–Q18
- Partial Class & Interface — Q19–Q24
- Boss Round — Q25–Q30

## Run locally
Open `index.html` in a browser.
